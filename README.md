# Pokemon Team Builder

Stack: React + Vite + Tailwind CSS. Data Pokemon dari PokeAPI.

## Cara menjalankan

Pastikan Node.js (versi 18 ke atas) sudah terinstal di komputermu.

1. Ekstrak folder ini, lalu buka terminal di dalamnya.
2. Install dependensi:

   ```
   npm install
   ```

3. Jalankan server development:

   ```
   npm run dev
   ```

4. Buka alamat yang muncul di terminal (biasanya `http://localhost:5173`).

Kalau berhasil, kamu akan melihat tulisan "⚡ Pokemon Team Builder — Setup project berhasil" dengan background gelap (menandakan Tailwind sudah aktif).

## Build untuk production

```
npm run build
```

Hasilnya ada di folder `dist/`, tinggal upload ke Vercel/Netlify/GitHub Pages.
